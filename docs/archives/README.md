# Archives documentaires

`requirements-notebook-original.txt` est une photographie de l’ancien
environnement d’exploration, conservée pour provenance. Ce fichier n’est utilisé
par aucune commande actuelle. Les dépendances de l’application sont définies
uniquement dans `requirements.txt`, à la racine.

Cette archive peut être supprimée si la conservation de cet ancien environnement
n’est plus utile. Les versions historiques restent accessibles dans Git.
